## 1. 升级背景：补齐纯懒压缩（v2.2）的三个真实工程盲区

在实验 07 中，我们证明了在 `50:1` 缓存折扣下，`0 → 384K` 纯追加锁死前缀缓存（`Cache-First Lazy`）显著优于固定步频中段重排（如 `billion-context` 的 50K 步频折叠）。但纯懒压缩仍存在三个生产级盲区：

1. **单次超大低熵工具输出的首轮未命中税（Oversized `tool_result` Miss Tax）**  
   若某次 `bash` 编译日志、全局 `grep` 或遥测 JSON 一次性吐出 `50K–110K` 低熵内容，即便后续命中缓存，首轮进入主模型仍需白交一次 `100K × $0.15/M` 未命中费；且 Pi 内置 `bash`（50KB 尾截断）与 `read`（2,000 行头截断）会静默丢弃首屏报错与深尾部代码。
2. **超长多代会话（2M–10M+ tokens，连续换代 5+ 次）的宏观因果脉络断裂**  
   仅靠 `$0` 确定性块目录在 1–2 次换代内足够准，但跨十几个换代纪元时缺少“前因后果决策脉络与已证伪死胡同账本”。
3. **未撞线（`< 384K`）但发生历史错误假设污染（Context Pollution）**  
   若前 `60K–150K` 走错方向留下大量错误推理定势，纯懒压缩不到 `384K` 不会清理，导致切新任务后模型持续受旧错误定势干扰且每轮白背旧包袱。

## 2. 三层 Cache-First v3 架构落地（`extensions/pi-cpat.ts` + `src/sidecar/tool-projector.ts`）

| 层级 | 触发时机 | 核心机制 | 对前缀缓存的影响 |
| :--- | :--- | :--- | :--- |
| **Layer 1：入窗前超大输出门控**<br/>(`pi.on("tool_result")`) | 写入时（进主模型与 KV Cache **之前**） | 拦截代码/Shell `>24K`、低熵结构化日志 `>28K`（模板冗余度 `>=0.36`）及硬上限 `>96K` 输出；同时从 `details.fullOutputPath` / 源文件**恢复宿主 50KB/2000 行截断盲区**，全量原文入 `SearchIndex`，向主会话返回 `~800–1400 tok` 高信号骨架（含全文 `Lstart-Lend` 符号跨度 + 早期 `ERROR/AssertionError` 诊断块）。 | **100% 纯追加（零回溯改写）**，直接省掉首轮 `$0.15/M` 未命中预填充税 |
| **Layer 2：显式任务/污染边界栈帧折叠**<br/>(`ScopeTree` + `AC3`) | 用户显式纠偏/切新任务（`before_agent_start`）、`/cpat-fold` 或 Agent 调 `context_checkpoint` | **绝不按固定 token 步频切分**；仅在显式子任务完结或推翻错误假设边界（此时 `suffixCachedTokens == 0`），用 `AC3` 权威源隔离规则将旧探索链折叠为 `context_edit(targetId, null)`，保留父级热前缀与底层无损 `SearchIndex`。 | **零后缀偏移（`suffixCachedTokens == 0`）**，Phase 2 首轮与次轮 100% 字节对齐 |
| **Layer 3：`384K` 同源前缀派生摘要**<br/>(`before_provider_request` + `session_before_compact`) | 撞击 `384K` 高水位换代瞬间 | 只读捕获上一轮温热请求体（`model + tools + messages`），在 `session_before_compact` 末尾直接追加摘要指令派生请求（**95%+ 命中刚跑满的 384K 热缓存，输入成本仅 `~$0.001`**），将「跨纪元因果决策脉络」与「多纪元分块无损 `SearchIndex` 目录」拼合。 | 换代摘要自身复用 **95%+ 热缓存**，彻底避免冷启动旁路高额重读 |
